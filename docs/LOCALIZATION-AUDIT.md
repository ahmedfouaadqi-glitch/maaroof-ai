## 2. البنية

- `src/lib/i18n/types.ts` — الأنواع المشتركة.
- `src/lib/i18n/{ar,en,ku}.ts` — قواميس منفصلة، مفتاح واحد لكل نص.
- `src/lib/i18n/index.tsx` — `I18nProvider`, `useI18n()`, `dirOf()`, و`serverT(lang, key)` للاستعمال خارج React (API، التصدير، الإشعارات).
- المفاتيح المولّدة آلياً تحمل البادئة `auto.` ومشتقّة من المعنى الإنجليزي لتبقى مقروءة.

## 3. الأدوات المستخدمة في المراجعة

| السكربت | الوظيفة |
| --- | --- |
| `scripts/i18n-audit.mjs` | فحص تغطية القواميس والمفاتيح الناقصة/المكررة |
| `scripts/i18n-extract.mjs` | استخراج كل السلاسل العربية وتصنيف نطاقها (مكوّن / وحدة / خادم) |
| `scripts/i18n-translate.mjs` | ترجمة السلاسل إلى EN + KU عبر بوابة الذكاء الاصطناعي مع ذاكرة تخزين |
| `scripts/i18n-codemod.mjs` | استبدال النصوص داخل المكونات بـ `t("key")` وحقن `useI18n()` |
| `scripts/i18n-fix-hooks.mjs` | ضبط موضع خطّاف الترجمة داخل المكوّن الصحيح |
| `scripts/i18n-module-pass.mjs` | تحويل ثوابت الوحدات (`label`, `hint`, خرائط التسميات) إلى مفاتيح وتغليف مواضع الاستخدام |

## 4. ما تم إصلاحه

- **42 ملفاً** من الصفحات والمكونات حُوِّلت نصوصها الصلبة إلى مفاتيح ترجمة، أبرزها:
  `MaaroofAdminTab` (155)، `SystemHealthTab`، `ModelDecisionPanels` (50)، `StateHermesPanels` (48)،
  `PublishingTrustPanels` (47)، `ExpertAcademyPanels` (42)، `admin.tsx` (42)، `HermesTaskCenter` (33)،
  `MaaroofStage` (30)، `maaroof.tsx` (29)، `MaaroofIntelligenceCenter` (29)، `ChannelsPanel` (25).
- **ثوابت الوحدات**: تسميات التبويبات، أوضاع الجدولة (`CADENCE_LABEL`, `APPROVAL_LABEL`)،
  حالات مهام هرمس (`STATUS_LABELS_AR`, `COMMAND_LABELS_AR`, `EXECUTION_MODE_LABELS_AR`)،
  وخطوات ربط القنوات (`tokenHelpSteps`) صارت مفاتيح تُترجم وقت العرض.
- **تقارير هرمس المصدَّرة** (`reportPayload`) تستقبل مترجم اللغة الحالية بدل العناوين العربية الثابتة.
- **عناوين الصفحات (SEO/head)** أُبقيت نصوصاً ثابتة عمداً لأنها تُقرأ قبل تشغيل React.
