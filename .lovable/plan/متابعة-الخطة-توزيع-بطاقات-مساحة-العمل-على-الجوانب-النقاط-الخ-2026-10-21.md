# متابعة الخطة: توزيع بطاقات مساحة العمل على الجوانب + النقاط الخمس المتبقية

## ثوابت
- تطوير فقط، دون تغيير الروابط أو أسماء الأدوات أو منطق الخصم أو النماذج.
- لا خصم إلا بعد النجاح، والكلفة والرصيد يظهران قبل التنفيذ.
- لا تُعرض نتيجة كحقيقة بلا دليل، وإلا تُوسم فرضية.
- الشعار والحركة الحالية بلا تغيير، ولوحة الإدارة خارج النطاق.

## 1. توزيع البطاقات في مساحة العمل (حاسوب)
```text
+-----------------+---------------------------+-----------------+
| النطاق الجغرافي |       صندوق الهدف         | الكلفة والرصيد  |
| المهارة         |       + المرفقات          | وزن المهمة      |
| نمط التشغيل     |       + زر البدء          | التصفح للمهمة   |
|                 |   (الخط الزمني أثناء      |                 |
|                 |    التنفيذ في الوسط)      |                 |
+-----------------+---------------------------+-----------------+
```
- عمود يمين للإعدادات (النطاق، المهارة، النمط)، الوسط للهدف والتنفيذ، عمود يسار للكلفة والوزن والتصفح.
- العمودان الجانبيان ثابتان أثناء التمرير.
- الشاشات المتوسطة: عمودان (الوسط عريض، والجانب يجمع البطاقات). الهاتف: عمود واحد بترتيب الهدف أولاً ثم الكلفة ثم الإعدادات.

## 2. التصفح الآمن داخل المهمة
- خيار في بطاقة جانبية: «السماح لمعروف بفتح صفحات لهذه المهمة» مع النطاقات.
- تفويض مؤقت مربوط بالمهمة، وكل صفحة مقروءة تظهر خطوة في الخط الزمني مع رابطها وكلفتها، بنفس قواعد الأمان الحالية.

## 3. بث الملفات
- زر «انشر في بطاقة السلطة» لكل ملف أو حقيقة موثقة، بعد موافقة.
- يضاف المعتمد إلى بطاقة السلطة العامة وملف llms.txt الخاص بالمستخدم، وتعرض لوحة البث ما نُشر وزيارات الزواحف.

## 4. القراءة الجماعية للملفات
- خيار «قراءة جماعية» يرسل الملف للنماذج الداعمة للنوع فعلاً، ويقارن القراءات (اتفاق/اختلاف).
- غير الداعم يظهر «غير مدعوم»؛ الفيديو قدرة محدودة موضحة. الكلفة لكل نموذج قبل التنفيذ، والنتائج تُحفظ حقائق بمصدرها.

## 5. معرفة حسابك
- زر «اجمع ما يعرفه معروف عني» يقرأ ملفك وبطاقة الكيان والمقابلات والمهام والمساحات، ويوزعها: الهوية، الروابط، الخدمات، الأسواق، المنافسون، الفجوات.
- الناقص بطاقة «ناقص» مع سؤال قصير. لا يُضاف اسم أو رابط لم تحفظه أنت.

## 6. الجولة التعريفية
- جولة قصيرة عند أول دخول، قابلة للإعادة من الإعدادات، مع تلميحات «؟» على كل بطاقة.

## التحقق
- اختبارات: تفويض التصفح المربوط بالمهمة، دعم الوسائط لكل نموذج، كلفة القراءة الجماعية، توزيع الحقائق حسب الفئة.
- لقطات حاسوب ولوح وهاتف، نهاري وليلي.
