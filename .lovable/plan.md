# سجل نتائج لكل أداة + تحميل أي نتيجة بأي صيغة

الهدف: كل مستخدم يرى أسفل كل أداة سجلاً بنتائجه السابقة لتلك الأداة فقط، ويستطيع تحميل أي نتيجة منها بالصيغة التي يريد (PDF، Excel، CSV، وورد، بوربوينت، Markdown، JSON) — كاملة وبنفس التذييل والهوية الحالية.

## 1) حفظ تلقائي للنتيجة

- عند ظهور أي نتيجة في أي أداة (نفس الأدوات الأربعة عشر التي فيها زر التصدير الآن) تُحفظ النتيجة تلقائياً في حساب المستخدم مرتبطة بمفتاح الأداة والتاريخ واللغة.
- التخزين يستخدم الجدول الموجود `report_drafts` (صاحب السجل فقط يقرأه) — لا حاجة لجدول جديد.
- يُحفظ الشكل الكامل للنتيجة كما يُصدَّر (بلا اقتطاع)، ويُمنع التكرار عند إعادة عرض نفس النتيجة.
- حد أعلى لكل مستخدم لكل أداة (آخر 50 نتيجة) مع حذف الأقدم تلقائياً.

## 2) لوحة «سجل نتائجي» أسفل كل أداة

- قسم قابل للطي أسفل نتيجة الأداة يعرض سجلات المستخدم لهذه الأداة فقط: العنوان + التاريخ والوقت + اللغة.
- لكل سجل: زر **تصدير** بقائمة الصيغ السبعة (نفس سياسة الإدارة والاستثناءات لكل مستخدم)، وزر **عرض** يُظهر ملخص الأقسام، وزر **حذف**.
- زر «تحديث» و«حذف الكل لهذه الأداة».
- إن كان المستخدم غير مسجّل الدخول أو التصدير معطّل لهذه الأداة، لا يظهر القسم.

## 3) الإدارة والخصوصية

- نفس سياسة التصدير الحالية تحكم السجل: الأدوات المسموحة، الصيغ المسموحة، والاستثناءات لكل مستخدم.
- لا أحد يرى سجل غيره (الإدارة فقط لديها وصول قراءة كما هي سياسة الجدول الحالية).

## 4) منشئ التقارير

مصدر «نتائج الأدوات» يتوسّع ليشمل السجلات المحفوظة (لا نتائج الجلسة الحالية فقط)، فيمكن دمج نتائج قديمة من عدة أدوات في تقرير واحد.

## تفاصيل تقنية

- جديد `src/lib/tool-history.functions.ts` بـ `requireSupabaseAuth`: `saveToolResult` (tool_key, title, payload, lang + تقليم إلى 50)، `listToolHistory(toolKey, limit)` (بدون payload للسرعة)، `getToolResult(id)`، `deleteToolResult(id)`، `clearToolHistory(toolKey)`.
- `src/components/ToolResultExport.tsx`: بعد بناء الـ payload يستدعي `saveToolResult` مرة واحدة لكل نتيجة (بصمة hash للمحتوى في `useRef` لمنع التكرار)، بصمت عند الفشل.
- جديد `src/components/ToolHistory.tsx`: جدول/قائمة بسيطة + `ExportButtons` لكل سجل (`build` يجلب الـ payload من `getToolResult` عند الطلب) + حذف، مع TanStack Query.
- إدراج `<ToolHistory toolKey="..." />` أسفل نتيجة كل أداة من الأربعة عشر (نفس أماكن `ToolResultExport`).
- `src/components/ReportBuilder.tsx`: قائمة السجلات المحفوظة إلى جانب نتائج الجلسة من `export-bus`.
- مفاتيح ترجمة جديدة (ar/en/ku): عنوان السجل، لا توجد نتائج، عرض، حذف، حذف الكل، تحديث، تأكيد الحذف.
- لا ترحيل قاعدة بيانات مطلوب (الجدول وسياساته موجودة)؛ فحص الأنواع + الاختبارات + البناء + تجربة فعلية: تشغيل أداة، ظهور السجل، تحميل نتيجة قديمة بـ PDF وExcel.
