# الخطة: المهارات الكاملة، النطاق الجغرافي، لغة التصدير، والدليل والسياسات

## 1. تحويل كل الأدوات إلى مهارات وربطها بالاشتراكات
- توسيع كتالوج المهارات ليغطي كل الأدوات الحالية (حضور، منافسون، جاهزية الكيان، استراتيجية النمو، محتوى للاقتباس، استخبارات السوق، الترتيب التطبيقي، الجدوى وتطوير الأعمال، تعزيز الانتشار، المراسلات، المحاكاة، التوطين، تدريب مساحة المعرفة).
- كل مهارة متاحة افتراضياً.
- الربط بالاشتراكات بالطريقة السابقة: المهارة تتبع الأدوات المفعّلة والمسعّرة في خطة المستخدم، وفوقها تحكم الإدارة المباشر (عام ← اشتراك ← مستخدم).
- المهارة المقيدة تظهر بشارة ترقية، والموقوفة تختفي عند الجميع.

## 2. صفحة الهبوط
- إخفاء رابط الواجهة الكلاسيكية.
- ترحيب حسب دولة الزائر وبلغته المختارة.
- لا تغيير على اسم العلامة (مؤجل حسب طلبك).

## 3. النطاق الجغرافي في مساحة العمل
- شريط أعلى صندوق الهدف: الدولة ← الإقليم ← المحافظة ← المدينة، أو «نطاق عالمي».
- يُحفظ في ملف المستخدم ويُرسل مع كل مهمة.

## 4. لغة التصدير المستقلة
- اختيار لغة التقرير (العربية / English / کوردی) داخل قائمة التصدير بغض النظر عن لغة الواجهة أو النص المكتوب.
- زر تصدير كامل لبطاقة النتيجة في مساحة العمل.

## 5. دليل المستخدم والسياسات
- استبدال الدليل بالكامل بدليل الواجهة الجديدة فقط (الأهداف، المهارات، النماذج العشرة، الفحص العميق، الأوضاع الثلاثة، الرصيد).
- تحديث شروط الاستخدام وسياسة الخصوصية.

## 6. التحقق
- تشغيل الاختبارات (منها اختبار صلاحيات المهارات) وفحص بصري على الحاسوب والهاتف.
