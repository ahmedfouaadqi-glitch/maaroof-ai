# المرحلة 1: الفحص العميق الحقيقي للحساب

## الهدف
تحويل بطاقة «الفحص العميق لحسابك» من معاينة إلى مهمة خلفية حقيقية موثقة، دون إعادة بناء أو تغيير مسارات، ودون أي خصم إلا عند النجاح.

## ما سيراه المستخدم
1. في الملف الشخصي تحت بطاقة الفحص: زر «ابدأ الفحص العميق» مع الكلفة التقديرية والرصيد الحالي.
2. نافذة تأكيد تعرض الروابط التي ستُفحص ومحاور كل رابط، ثم موافقة صريحة.
3. شريط تقدم صغير لا يمنع التصفح، ويستمر بعد إعادة تحميل الصفحة.
4. النتيجة لكل رابط ولكل محور: حكم + دليل + سبب + خطوة تالية. المحور بلا دليل يظهر «لم يُقَس بعد» ولا يدخل في الدرجة.
5. درجة إجمالية مرجّحة حسب نوع الحساب، وزر تصدير بأي لغة.
6. بلا روابط: يُفحص الاسم والهوية فقط مع رسالة واضحة، دون اختلاق.

## قواعد ثابتة
- الموقع الرسمي: SEO + AEO + GEO + SGE + GSEO. الصفحات الداخلية: SEO + AEO + GEO + SGE. حسابات التواصل: GSEO + GEO (اتساق الاسم والوصف والرابط والتشابه).
- ترتيب الأولوية حسب الأنواع السبعة (موجود في الدوال الحالية).
- الخصم مرة واحدة عبر نظام الرصيد الحالي بعد النجاح فقط؛ الفشل الكامل لا يُحسب؛ الجزئي يُحسب على الروابط المنجزة فقط.
- لا تكرار عند إعادة المحاولة: مهمة فعالة واحدة لكل مستخدم.
- لا ذكر لمزودي الخدمة أو الوسطاء في الواجهة أو التصدير.

## التفاصيل التقنية
- إعادة استخدام `maaroof_jobs` و`maaroof_job_events` و`runAfterResponse` بنمط `mode = "deep_audit"`؛ لا جداول جديدة.
- مسار جديد `src/routes/api/deep-audit.ts`: POST للتقدير (بدون خصم)، POST للتشغيل بعد الموافقة؛ التحقق من الجلسة وملكية المستخدم.
- منفّذ خالص الحدود `src/lib/maaroof/deep-audit.server.ts`: يقرأ كل رابط عبر قارئ المواقع الحالي (مع الذاكرة المؤقتة)، يحسب المحاور بقواعد حتمية من المحتوى الفعلي (العنوان، الوصف، العناوين، البيانات المهيكلة، llms.txt، كثافة الحقائق في أول 150 كلمة، اتساق الاسم مع بطاقة الحقيقة)، ويكتب حدثاً لكل رابط.
- التسعير عبر `chargeTokens` بمفتاح `deep_audit` مع وحدات لكل رابط، والرجوع لسعر الأداة الأم إن لم يُسعَّر.
- المتابعة عبر `/api/maaroof-jobs` الحالي.
- واجهة: مكون `DeepAuditRunner` داخل `EntityFields.tsx`، وعرض النتائج في `/workspace` ضمن سجل المهام، والتصدير عبر `exports.ts` الحالي.
- اختبارات: تحويل الصفحة إلى درجات المحاور، المحور بلا دليل = null، عدم الخصم عند الفشل، الخصم الجزئي، منع المهمة المكررة.
