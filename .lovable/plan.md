# متابعة الخطة: آخر ثلاثة أجزاء

تم: قائمة الأدوات مع الكلفة قبل التنفيذ، استخدام روابط التواصل لمن لا يملك موقعاً، حساب مؤشر SEO/AEO/GEO ومقارنة التطور (67 اختباراً ناجحاً). كل ما يلي تطوير للموجود، بلا نشر دون موافقتك.

## 1. نوع الحساب في الملف الشخصي
- خيار ثلاثي: مؤسسة / صانع محتوى / فرد بلا موقع، داخل بطاقة الهوية الحالية.
- اقتراح تلقائي: لا موقع + روابط تواصل = صانع محتوى؛ لا موقع ولا روابط = فرد. المستخدم يؤكد أو يغيّر.
- يحترم قفل البطاقة الحالي (التغيير بعد التوثيق يمر بإعادة التحقق المعتادة).

## 2. إظهار المؤشر والتطور
- في الملف الشخصي: ثلاث بطاقات SEO / AEO / GEO، كل منها رقم وأسبابه، أو «لم يُقَس بعد».
- في شاشة معروف وأداة الظهور: سطر المقارنة مع الفحص السابق عند وجود فحصين حقيقيين.
- تحسين: زر «قِس الآن» بجانب GEO يفتح أداة الظهور بدل رقم فارغ.

## 3. عدم تكرار الأسئلة
- إجابات أسئلة الاستيضاح تُحفظ لحسابك، وتُستخدم تلقائياً في الجلسات التالية.
- يظهر سطر صغير: «استخدمنا إجابتك السابقة: …» مع زر تعديل.

## التحقق
- اختبارات لكل جزء، فحص الأنواع، وتجربة فعلية في المعاينة بحسابك.

## تفاصيل تقنية
- `profile.tsx`: حقل `entity_type` بالقيم organization|creator|individual (العمود موجود نصياً؛ `u.$username.ts` يعامل creator/individual كـ Person).
- بيانات المؤشر: `crawler_hits` (عدّ حسب البوت)، `entity_*` من profiles، آخر سبر من `report_drafts`/نتائج visibility؛ عرض عبر `trinityScore` و`compareProbes`.
- الإجابات المحفوظة عبر `remember`/`recall` الموجودة في `memory.server.ts` بمفتاح `clarify:<field>`، تُدمج في `clarifications` قبل `missingFields`.
