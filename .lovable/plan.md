# الخطة: (1) تغذية مساحة المعرفة بملف المشروع، ثم (2) المحادثة والبطاقات الحية بأسلوب React Bits

## المبادئ
- تطوير فقط: لا مسارات جديدة، لا إعادة تسمية، لا منطق متداخل.
- لا ادعاء: كل معلومة تُخزَّن بمصدرها ودرجة ثقتها، وما لم يُؤكَّد يُعلَّم «فرضية» حتى توافق عليه.
- React Bits: نسخ وتكييف مكوناته المفتوحة داخل المشروع (طريقته الرسمية) دون حزم ثقيلة جديدة، مع احترام تقليل الحركة وتبسيطها على الهاتف.

## المرحلة 1: تغذية مساحة المعرفة بملف المشروع
1. جمع ما هو موجود فعلاً فقط: إجابات المقابلة المحفوظة لمساحة maaroofai.com، بطاقة حقيقة الكيان في ملفك، الموقع الرسمي وملف llms.txt، وصف المنصة (المحاور الخمسة، النماذج العشرة، المهارات السبع عشرة، أنواع الحسابات السبعة).
2. تحويلها إلى حقائق معرفة مرتبطة بحسابك ومساحتك، كل منها بمصدر (مقابلة / ملف / موقع / وصف المنصة) وثقة وتاريخ صلاحية.
3. ما لا دليل عليه (مثل ملكية النطاقات الأخرى أو أرقام الأداء) يُحفظ كفرضية تنتظر موافقتك، ولا يُعرض كحقيقة.
4. بطاقة «ماذا يعرف معروف عنك» تعرض الملخص بصيغة المتكلم مع شارة دليل/فرضية وأزرار: أوافق، صحّح، احذف.
5. تصدير «حزمة معرفة المشروع» إليك (عربي، مع إمكانية الإنجليزية/الكردية) لمراجعتها.

## المرحلة 2: المحادثة اليومية والبطاقات التفاعلية
### المحادثة
- عدّاد ظاهر للرسائل المجانية المتبقية اليوم ووقت التجدد (مثل Lovable)، يتحول لعرض الكلفة لأصحاب الرصيد.
- اختيار سياق المحادثة: عامة، أو مرتبطة بمهمة سابقة (تقرأ نتيجتها وأدلتها)، مع زر «ابدأ مهمة من هذه المحادثة».
- رسائل بكشف تدريجي للنص ومؤشر «معروف يفكّر» متحرك.

### البطاقات الحية أثناء المهمة/الخطة/المحاكاة
- خط سير من بطاقات: فهم الطلب، الخطة والكلفة، مجلس النماذج العشرة، جمع الأدلة، حل التعارض، النتيجة.
- كل بطاقة: حالة نابضة (ينتظر / يعمل / اكتمل / تخطّى مقصوداً / تعذّر مع السبب)، شرح بجملة واحدة لما يحدث، وعدّاد التوكن المستهلك فعلاً.
- شبكة النماذج العشرة بشعاراتها وحالة كل نموذج لحظياً.
- السجل النصي يبقى متاحاً كخيار «التفاصيل».

### مكونات React Bits المكيَّفة
SpotlightCard، AnimatedList، CountUp، ShinyText، BlurText (موجود)، GlareHover خفيف، StarBorder لحدود البطاقة النشطة.

## التحقق
- اختبارات: حدّ المحادثة والتجدد، تحويل الأحداث إلى حالات البطاقات، تمييز الدليل عن الفرضية.
- فحص الأنواع، ولقطات للمساحة والمحادثة والبطاقات على الحاسوب والهاتف والوضع الليلي.
- لا عمليات مدفوعة أثناء التحقق.
