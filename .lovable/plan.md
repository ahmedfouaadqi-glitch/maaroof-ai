# إصلاح تعذر دخول صفحة الوكيل (معروف)

## السبب المؤكد
في `src/routes/maaroof.tsx` السطر 222 يوجد `useState` لـ `toolPick` بعد الخروج المبكر في السطر 201 (`if (loading || !user) return <AuthGate/>`). عند انتقال الحالة من "جاري التحميل/غير مسجل" إلى "مسجل" يتغير عدد الـ Hooks فيرمي React خطأ ويظهر «This page didn't load».

## الإصلاح
1. نقل `const [toolPick, setToolPick] = useState<string[] | null>(null)` إلى أعلى `MaaroofPage` مع بقية الـ Hooks (بعد السطر 78).
2. الإبقاء على السطر 223 (`picked`) كما هو لأنه حساب عادي وليس Hook؛ والتأكد من أن أي `useMemo/useEffect` آخر بعد السطر 201 يُنقل أيضاً.
3. التحقق في المعاينة: فتح `/maaroof` مسجلاً الدخول دون خطأ في console، دون تشغيل جلسة تخصم رصيداً.

- المعاينة تتحدث تلقائياً بعد الإصلاح.
- مزامنة GitHub في Lovable ثنائية الاتجاه وتلقائية: تُدفع التعديلات إلى المستودع المتصل بعد الحفظ. لا أستطيع تنفيذ أوامر git بنفسي؛ إن لم يكن المستودع متصلاً فيجب ربطه من إعدادات المشروع (GitHub).
- النشر للموقع المنشور لا يتم إلا بموافقتك الصريحة بعد عرض الملخص والاختبارات (قاعدة المستودع المحفوظة).
