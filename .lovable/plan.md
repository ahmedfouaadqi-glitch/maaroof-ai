## خطة إضافة "الوكيل الذكي" كخدمة إضافية

### 1) قاعدة البيانات (migration)
- **`agent_addons`** — الباقات الإضافية للوكيل (lite/pro/business): الاسم، السعر بالدينار، الحد الشهري للمهام، عدد المواقع، الميزات.
- **`user_agent_subscriptions`** — اشتراك المستخدم في الوكيل: `user_id`, `addon_id`, `status` (pending/active/expired), `tasks_used`, `period_start`, `expires_at`.
- **`agent_tasks`** — سجل مهام الوكيل: `user_id`, `task_type` (analyze_url / suggest_post / monitor_geo)، `target` (URL/topic)، `result` (jsonb)، `status`، `scheduled_for`، `created_at`.
- **`agent_targets`** — المواقع/الصفحات التي يراقبها الوكيل لكل مستخدم.
- RLS كامل: المستخدم يرى/ينشئ بياناته فقط، السوبر ادمن يرى الكل ويفعّل الاشتراكات.
- Seed: 3 باقات (Lite 20,000 / Pro 50,000 / Business 120,000 د.ع).

### 2) صفحة الأسعار `/pricing`
- إضافة قسم جديد تحت الباقات الأساسية بعنوان **"إضافة: الوكيل الذكي 🤖"**.
- 3 كروت لباقات الوكيل مع أمثلة "ما يفعله الوكيل لك" بشكل مبسّط.
- زر "أضف الوكيل لاشتراكي" → نفس فلو التواصل عبر واتساب/إيميل (مع تسجيل `subscription_requests` بنوع `agent_addon`).
- توضيح: "تحتاج اشتراك أساسي فعّال لتفعيل الوكيل".

### 3) لوحة الوكيل `/agent` (للمستخدم)
- صفحة جديدة محمية بالمصادقة + اشتراك وكيل نشط.
- إضافة/إدارة المواقع المراقَبة (`agent_targets`).
- عرض المهام الأخيرة ونتائجها (تحليل GEO، اقتراحات منشورات، تنبيهات).
- شريط استهلاك المهام الشهرية (X / الحد الأقصى).
- زر "شغّل مهمة الآن" يدوياً (تحليل/اقتراح).

### 4) الـ Cron Job (تشغيل تلقائي)
- مسار عام `src/routes/api/public/hooks/agent-runner.ts` يحقق المصادقة بـ `apikey` header.
- المنطق: يجلب كل المستخدمين النشطين بالوكيل، يقرأ `agent_targets` لكل واحد، ويولّد مهام (تحليل + اقتراح) عبر Lovable AI Gateway، يسجلها في `agent_tasks`، ويزيد `tasks_used`.
- جدولة عبر `pg_cron`: مرة يومياً صباحاً + مرة أسبوعية لتقرير شامل.
- حماية من تجاوز الحد: إيقاف فوري عند بلوغ `tasks_used >= monthly_tasks`.

### 5) لوحة السوبر ادمن (`/admin`)
- تبويب جديد **"اشتراكات الوكيل"**: قائمة الطلبات المعلقة + زر "تفعيل" (ينشئ `user_agent_subscriptions` نشط لمدة 30 يوم).
- قائمة المواقع المراقبة (إجمالي) ومتوسط الاستهلاك (لمراقبة التكلفة).

### 6) الترجمة (i18n)
- مفاتيح جديدة في AR/EN/KU لكل النصوص (الوكيل، المواقع، التقارير، المهام، إلخ).

### تفاصيل تقنية

**Stack:** TanStack Start server routes + Lovable Cloud (Postgres + pg_cron + pg_net) + Lovable AI Gateway (gemini-2.5-flash).

**حماية التكلفة:**
- حد يومي صارم لكل مستخدم (مثلاً 10 مهام/يوم بحد أقصى).
- استخدام `gemini-2.5-flash` (الأرخص) لمهام الوكيل التلقائية.
- توقف فوري عند انتهاء الاشتراك أو بلوغ الحد الشهري.

**فلو التفعيل:**
1. المستخدم يضغط "أضف الوكيل" → ينشئ `subscription_request` بنوع `agent_addon`.
2. يتواصل عبر واتساب/إيميل ويدفع.
3. السوبر ادمن يضغط "تفعيل" → يُنشأ `user_agent_subscriptions` نشط 30 يوم.
4. أول cron run سيلتقطه ويبدأ توليد المهام.

**هامش الربح المتوقع:** 88-92% على كل باقة (تكلفة AI الفعلية ≈ 8-12% من السعر).
