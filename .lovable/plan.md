ملاحظة: لا أداة جديدة. كل شيء يُضاف داخل `BrandBoostAgent.tsx` و `api/brand-boost.ts` و `lib/platform-probe.server.ts`، مع جدول صغير واحد لتتبّع الزحف.

## أولاً: نقاش "حقيقي / وهمي" — ما الذي سيُبنى ولماذا

| البند | الحالة | لماذا |
|---|---|---|
| **استقبال مزدوج (Scrape + Survey)** | ✅ حقيقي | Firecrawl يقرأ الموقع + 3 حسابات سوشيال. الـsurvey يملأ الفجوات. |
| **توليد JSON-LD + Markdown موجّه لكل LLM** | ✅ حقيقي | عبر Lovable AI Gateway. كل منصة (ChatGPT/Gemini/Claude…) تحب صيغة مختلفة. |
| **نقاط استقبال للزواحف `/api/public/brand/[slug]`** | ✅ حقيقي | URL ثابت يقرأه GPTBot/Google-Extended/PerplexityBot. هذا فعلاً ما يفعله المحترفون. |
| **IndexNow + Google Indexing API ping** | ✅ حقيقي ومجاني | يسرّع الفهرسة من أيام إلى ساعات. |
| **Propagation Tracker (متتبّع الانتشار)** | ✅ حقيقي | نقرأ User-Agent على نقطة الاستقبال ونسجّل: GPTBot زار قبل ساعتين، PerplexityBot قبل يوم… دليل مرئي للمستخدم. |
| **إعادة فحص الظهور كل أسبوع (probe موجود أصلاً)** | ✅ حقيقي | نقارن قبل/بعد ونعرض رسم بياني. |
| ~~تحديث Wikidata تلقائياً~~ | ❌ وهمي/خطر | يؤدي لحظر الحساب. نستبدله بـ "تعليمات يدوية + قالب جاهز للنسخ". |
| ~~نشر "أخبار منظَّمة" لعدة مواقع~~ | ❌ وهمي | يتطلب PRNewswire مدفوع أو يصبح سبام. نستبدله بـ "حزمة محتوى جاهزة + قائمة قنوات يدوية". |
| ~~تدريب عميق / أوزان النماذج~~ | ❌ وهمي بالكامل | لا أحد يؤثر على تدريب OpenAI/Google. نشطب الادعاء. |
| ~~Positive Poisoning / Flooding~~ | ❌ خطر | يُصنّف سبام ويضر العلامة. نشطبه. |

**النتيجة:** نبني فقط الـ ✅ ونحذف الـ ❌ من المقترح الأصلي.

## ثانياً: ما يُضاف داخل الأداة (الواجهة)

في نفس بطاقة `BrandBoostAgent`، يُضاف تبويبان فوق النتائج الحالية:

```text
[ تشغيل التعزيز ]  [ محرّك السلطة ]  [ متتبّع الانتشار ]
```

### تبويب "محرّك السلطة" (Authority Engine)
- زر **«ولّد حزمة السلطة»** → يستدعي `/api/brand-boost` مع `mode: "authority"`.
- يعرض:
  - **JSON-LD** (Organization + Person + FAQ + Article) — زر نسخ + زر "انشر تلقائياً على نقطة الاستقبال".
  - **Markdown Brand Card** — صفحة موحّدة موجَّهة للزواحف.
  - **رابط نقطة الاستقبال العامة**: `…/api/public/brand/{slug}` — يخبر المستخدم: «هذا الرابط يقرأه GPTBot وغيره مباشرة».
  - **زر "أرسل IndexNow + Google Ping"** — مجاني، يسرّع الفهرسة.
  - **تعليمات Wikidata يدوية** (نص جاهز للنسخ، بلا أتمتة).

### تبويب "متتبّع الانتشار" (Propagation Tracker)
جدول بسيط من جدول `crawler_hits`:

| الزاحف | آخر زيارة | عدد الزيارات (7 أيام) | الصفحات |
|---|---|---|---|
| GPTBot | قبل ساعتين | 12 | /brand/acme |
| PerplexityBot | قبل يوم | 4 | /brand/acme |
| Google-Extended | قبل 3 أيام | 7 | /brand/acme |

+ شارة خضراء: «علامتك مرئية لـ 4 من 6 زواحف هذا الأسبوع».

## ثالثاً: الجزء التقني (للمراجعة الفنية)

### 1. تعديل ملفات موجودة (لا ملفات جديدة كبيرة)
- `src/components/BrandBoostAgent.tsx` — إضافة Tabs + قسمَين جديدَين (UI فقط).
- `src/routes/api/brand-boost.ts` — قبول `mode: "boost" | "authority"`. في authority: يولّد JSON-LD/Markdown ويحفظ في `brand_authority_packs`.
- `src/lib/platform-probe.server.ts` — لا تغيير (يُعاد استخدامه للقياس قبل/بعد).

### 2. ملف جديد واحد
- `src/routes/api/public/brand/$slug.ts` — نقطة استقبال عامة (GET):
  - تُرجع HTML + JSON-LD مضمَّن + Markdown.
  - تقرأ `User-Agent` وتُسجّل في `crawler_hits` (insert فقط، لا قراءة من العميل).
  - بلا مصادقة (تحت `/api/public/*`).

### 3. جدولان جديدان (Supabase migration)
```sql
brand_authority_packs (
  id, user_id, brand_slug unique,
  json_ld jsonb, markdown text, html text,
  created_at, updated_at
)

crawler_hits (
  id, brand_slug, user_agent, bot_name,
  path, hit_at, ip_hash
)
-- RLS: المستخدم يرى hits علامته فقط
```

### 4. مفاتيح/أسرار
- `FIRECRAWL_API_KEY` — موجود ✅
- `LOVABLE_API_KEY` — موجود ✅
- IndexNow — مفتاح يولَّد محلياً، بلا تسجيل ✅
- Google Indexing API — اختياري، يطلب من المستخدم لاحقاً.

## رابعاً: التكلفة

### تكلفتك (المالك) لكل مستخدم/شهر:
| البند | التكلفة |
|---|---|
| Firecrawl (موقع + 3 سوشيال × 4 مرات/شهر) | 0.10$ – 0.30$ |
| Lovable AI (توليد JSON-LD + محتوى لـ 8 منصات) | 0.05$ – 0.15$ |
| استضافة نقطة الاستقبال + سجلات الزواحف | 0.02$ |
| IndexNow / Google Indexing | مجاني |
| **الإجمالي** | **~ 0.20$ – 0.50$ / مستخدم / شهر** |

### تكلفة المستخدم:
- **التكلفة الحالية للأداة:** 5 credits لكل تشغيل (بدون تغيير).
- **محرّك السلطة:** +3 credits لكل توليد حزمة (مرة واحدة، ثم تحديث شهري).
- **متتبّع الانتشار:** مجاني (قراءة من جدول).
- **اقتراح تسعير حزمة شهرية مدمجة:** +5$ – 10$ فوق Brand Boost الحالي.

هامش الربح: ~ 95%.
