# خطة تطوير النتيجة الثانية: مصنف تشغيلي واضح + كلمات لكل نموذج + llms.txt

تطوير لما هو موجود فقط (قارئ الجداول، market-scope، competitive-geo، operational-workbook، dual-result، Dardasha). لا تغيير لصفحة الهبوط ولا لمسميات المحركات العشرة.

## 1. ملف إكسل نظيف بلا تكرار (6 تبويبات فقط)
1. ابدأ هنا: ملخص بسيط بلغة واضحة (ماذا وجدنا، ماذا نفعل الآن).
2. الكلمات حسب الأسواق: كلمة، سوق، لغة، محور (GEO/SEO/SGE/AEO/Social)، المصدر.
3. الكلمات لكل نموذج: كلمة، الصيغة المناسبة لكل نموذج، النماذج التي ذكرتها بالاسم، درجة التطابق (عدد النماذج من 10)، المحور الموصى به وسببه.
4. العلامة مقابل المنافسين: لكل سوق، الحصة الصوتية، كثافة الحقائق، بطاقة السلطة، نقاط القوة والضعف — بمصدر لكل خلية، و«غير متوفر» عند غياب الدليل.
5. الكلمات السلبية: قائمة منظفة بلا تكرار جاهزة للنسخ إلى Google Ads.
6. خطة التنفيذ: كل خطوة مع «كيف تُنفذ» و«من ينفذها»: نفّذها معروف (مع الناتج) أو تحتاج فريقك.
- المصادر تُجمع في عمود واحد داخل كل تبويب بدل تبويب مكرر لكل ورقة.

## 2. اكتشاف المنافسين آلياً
- إلغاء طلب أسماء المنافسين؛ تُكتشف لكل سوق عبر بحث الويب وإجابات المحركات العشرة، وتظهر للمستخدم مع سبب اختيار كل منافس.
- حقل المنافسين يبقى اختيارياً للإضافة فقط.

## 3. الكلمات لكل نموذج ودرجة التطابق
- لكل كلمة رابحة: يُسأل المجلس العشري بسؤال محايد موجّه للسوق، ويُسجّل أي نموذج ذكر العلامة أو المنافس.
- درجة التطابق = عدد النماذج المتفقة / 10، مع أسمائها.
- الصيغة لكل نموذج مبنية على نمط استرجاعه، وتُوسم «مقترحة» لا «مقاسة».

## 4. llms.txt وحزمة الآلة جاهزة للوضع مباشرة
- معروف يولّد llms.txt وJSON-LD للمنظمة وFAQPage من بيانات الحساب والأسواق المؤكدة ونتائج البحث فقط، مرتبة وصالحة لكل النماذج العشرة.
- أزرار في الدردشة: نسخ llms.txt، تحميل الكلمات السلبية، تحميل المصنف الكامل، وباقي صيغ التصدير.

## 5. طبقة الإسكندرية والتواصل الاجتماعي
- أول خطوة: فحص هل الطبقة متصلة فعلاً وتعيد نتائج. إن لم تعمل يُذكر ذلك صراحة في النتيجة ولا يُختلق بديل.
- إضافة تبويب فرعي للكلمات المنشورة على المنصات الاجتماعية من صفحات عامة فقط، مع الرابط.

## 6. ما ينفذه معروف تلقائياً
- كل خطوة قابلة للتنفيذ (llms.txt، Schema، قائمة سلبيات، مجموعات إعلانية) تُنتج فوراً وتظهر في النتيجة بحالة «نُفّذ».
- الخصم فقط عند النجاح، بالرصيد الموحد، مع عرض التكلفة مقابل الرصيد قبل البدء.

## تفاصيل تقنية
- `operational-workbook.ts`: إعادة تجميع إلى 6 أوراق، إزالة تكرار المصادر والسلبيات، أعمدة engine_match و match_score.
- `competitive-geo.server.ts`: discoverCompetitors لكل سوق، تسجيل ذكر كل محرك لكل كلمة.
- `machine-pack.ts`: إعادة استخدامه لتوليد llms.txt من النتيجة.
- `dual-result.ts`: إزالة clarify الخاص بالمنافسين، إضافة حالة تنفيذ لكل خطوة.
- `Dardasha.tsx`: أزرار النسخ والتحميل.
- فحص اتصال الإسكندرية قبل الاعتماد عليها.
- اختبارات: 6 تبويبات، لا تكرار، حساب درجة التطابق، لا خلية بلا مصدر.
