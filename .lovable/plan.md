# تصدير نتائج كل الأدوات عبر منشئ التقارير

الهدف: أي نتيجة تظهر في أي أداة (اقتراح المنشورات، التحليل، مقارنة المنافسين، الجدوى، الأبحاث، الظهور… إلخ) يمكن للمستخدم تحميلها بالصيغة التي يختارها، كاملة بلا اقتطاع، بهوية الموقع (الشعار، الاسم، الألوان) واسم المستخدم مع بريد مُقنَّع، ومع تحكّم إداري كامل عام ولكل مستخدم.

## 1) طبقة التقاط النتائج (ربط الأدوات بمنشئ التقارير)

- ناقل نتائج مشترك: كل أداة تسجّل نتيجتها الأخيرة (عنوان + أقسام) في مخزن واحد في الجلسة.
- منشئ التقارير يعرض مصدراً جديداً: «نتائج الأدوات الحالية» بجانب مصادره من قاعدة البيانات، فيمكن دمج نتيجة أداة واحدة أو عدة أدوات في تقرير واحد.
- كل أداة تحصل على أزرار تصدير في رأس نتيجتها (تُخفى تلقائياً حسب سياسة الإدارة الحالية).

## 2) اكتمال المخرجات (بلا فقدان أي عنصر)

- إزالة كل الاقتطاعات الحالية في بناء التقرير (حد 50 صفاً، 6 أعمدة، 120/200 حرفاً) — تُصدَّر كل الصفوف والأعمدة والنصوص كاملة.
- PDF: قواعد طباعة تمنع قطع الجداول والعناوين بين الصفحات، وترقيم صفحات، وتكرار رؤوس الجداول.
- الصيغ المتاحة: PDF، Excel، CSV، Word، PowerPoint، Markdown، JSON (كلها موجودة وتُوحَّد داخل زر صيغ واحد).

## 3) الهوية والخصوصية في التذييل

تذييل موحّد في كل الصيغ: الشعار + «MAAROOF Ai» + maaroofai.com + اسم المستخدم + البريد المُقنَّع + التاريخ + إخلاء المسؤولية، بألوان الموقع.

- تقنيع البريد: `ah****f@g****.com` (افتراضي)، أو بديل «رمز مختصر» (بصمة قصيرة غير قابلة للعكس)، أو إخفاء كامل — يحدده الإعداد الإداري.
- تصحيح النصوص القديمة: `geoiraq.com` ← `maaroofai.com`.

## 4) تحكّم الإدارة (عام + لكل مستخدم)

توسيع إعداد `export_config` الحالي ليشمل:

- الصيغ المسموحة (تفعيل/إيقاف كل صيغة على حدة).
- الأدوات المسموح التصدير منها (موجود) + حد أقصى اختياري للصفوف.
- خيارات التذييل: إظهار اسم المستخدم، مستوى تقنيع البريد، إظهار الشعار.
- استثناءات لكل مستخدم: جدول جديد `user_export_overrides` (قراءة للمستخدم لسجله فقط، كتابة للإدارة) يتجاوز السياسة العامة لحساب معيّن — بحث بالبريد، تفعيل/إيقاف، صيغ مخصّصة.

لوحة الإدارة: يُطوَّر تبويب «إعدادات التصدير» الحالي بأقسام: النمط العام، الصيغ، الأدوات، التذييل والخصوصية، استثناءات المستخدمين — بثلاث لغات.

## تفاصيل تقنية

- `src/lib/exports.ts`: إضافة `identity` و`footer` إلى `ExportPayload`، تذييل موحّد لكل الصيغ، ثوابت العلامة، CSS طباعة (`break-inside: avoid`, `thead{display:table-header-group}`, `@page` counter).
- جديد `src/lib/export-identity.ts`: بناء هوية المستخدم من `profiles` + `auth` وتقنيع البريد.
- جديد `src/lib/export-bus.ts`: مخزن خفيف (Map + subscribe) لنتائج الأدوات في الجلسة + hook `useToolResultCapture(toolKey, build)`.
- `src/components/ExportButtons.tsx`: قائمة صيغ موحّدة، تمرير الهوية، احترام الصيغ المسموحة والاستثناءات.
- إضافة الأزرار داخل نتائج: `PostSuggester`, `Sandbox` (تحليل), `CompetitorCompare`, `FeasibilityStudy`, `BizDev`, `SmartResearch`, `AIVisibility`, `GeoStrategist`, `WhatIfSimulator`, `SocialAnalysis`, `AppliedRanking`, `BrandBoostAgent`, `CompanyOutreach`, `CompetitorMonitor`.
- `src/lib/content.ts`: توسيع `ExportConfig` (صيغ، تذييل) مع قيم افتراضية متوافقة رجعياً.
- ترحيل قاعدة بيانات: جدول `user_export_overrides` مع GRANT وRLS (المستخدم يقرأ سجله، الإدارة تقرأ/تكتب الكل).
- `ReportBuilder.tsx`: مصدر «نتائج الأدوات» + إزالة الاقتطاعات.
- مفاتيح ترجمة جديدة في ar/en/ku.

بعد التنفيذ: فحص الأنواع + الاختبارات + البناء، وتجربة فعلية لتصدير نتيجة أداة بصيغتي PDF وExcel للتأكد من اكتمال المحتوى والتذييل.
