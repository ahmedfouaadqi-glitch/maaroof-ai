# إكمال الخطة: الحساب ومساحة العمل وسجل العمل + ملاحظتاك

## ملاحظتاك
1. **مثال حقيقي لبطاقة الحقيقة:** نعرض بطاقة «معروف» نفسها (MAAROOF Ai)، وتُقرأ بياناتها الفعلية من بطاقته العامة (الاسم، النوع، البلد، الروابط الرسمية، نسبة الاتساق المحسوبة بالقواعد الحالية). إن تعذّرت القراءة يُخفى المثال بدل عرض أرقام مختلقة.
2. **عدد المهارات مرتبط بالإدارة:** قسم المهارات والرقم المتحرك يعرضان فقط المهارات التي تفتحها الإدارة حالياً للمستخدمين، فيزيد أو ينقص تلقائياً عند تغيير الإعداد في لوحة الإدارة. وأضيف في لوحة الإدارة مفتاح تشغيل/إيقاف لكل مهارة إن لم يكن موجوداً.

## المرحلة C: حساب المستخدم
- صفحة الدخول/التسجيل: بطاقة زجاجية بإضاءة تتبع المؤشر، انتقال ناعم بين الوضعين، رسائل أخطاء عربية واضحة.
- معالج ترحيب عند أول دخول (قابل للتخطي): نوع الحساب من السبعة ← الاسم والبلد والروابط ← الأهداف، ويحفظ في بطاقة الحقيقة.
- تحذير تشابه الأسماء والبلدان، وتنبيه عند غياب موقع رسمي أو حسابات تواصل.
- الشريط العلوي: رصيد بعدّاد متحرك وشارة نوع الحساب.
- الملف الشخصي: الأنواع السبعة، ومؤشر اكتمال الملف.
- مساحة العمل: شارات نبض لحالة كل نموذج، وعدّاد وزن المهمة (خفيفة/متوسطة/عميقة) قبل التنفيذ.
- الهاتف: شريط تنقل سفلي.

## المرحلة D: سجل العمل والأدوات
- تعريب أسماء المراحل (التصور، التخطيط، المجلس، حل التعارض).
- التخطي المقصود يظهر «متخطى» لا «فشل».
- ملخص عربي مقروء للمقارنة والاستراتيجي وتعزيز العلامة بدل «نتيجة أداة».
- عدم تمرير منافس شكلي عند تعذر أداة سابقة.
- التصدير: اتجاه نص تلقائي حسب لغة المحتوى.
- تسعير تعليم المساحة والمقابلة عبر جدول الأسعار الحالي.
- مهمة الاستكشاف الخلفي للكيان تُترك لدفعة لاحقة منفصلة لأنها تستهلك رصيداً وتحتاج مراجعتك.

## التحقق
- الاختبارات الحالية (85) + اختبارات: الأنواع السبعة والتشابه، وزن المهمة، التخطي مقابل الخطأ، فلترة المهارات حسب إعداد الإدارة، اتجاه التصدير.
- لقطات للرئيسية والدخول والملف ومساحة العمل على الحاسوب والهاتف. لا نشر ولا عمليات مدفوعة.

## تفاصيل تقنية

- المهارات: فلترة `MAAROOF_SKILLS` بإعداد الإدارة عبر `skill-access-policy.ts` / `use-interface-policy`، وتبديل لكل مهارة في `InterfacesAdminPanel.tsx`.
