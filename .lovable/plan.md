# توحيد حفظ الملف الشخصي وربطه بالصفحة العامة

## المشكلة
- زر «حفظ» الرئيسي لا يحفظ حقول الهوية (النوع، المقر، الأسواق، التخصص، الروابط)، فتعود فارغة بعد الحفظ.
- الصفحة العامة لا تقرأ حقول الهوية، فتبقى على التفاصيل القديمة.
- الأدوات الأخرى فُحصت ولا تتأثر بهذه المشكلة.

## الحل
1. **زر حفظ واحد شامل** في الملف الشخصي يحفظ كل شيء دفعة واحدة: الاسم، العلامة، الكلمات، اسم المستخدم، وكل حقول الهوية. تبقى القيم كما كتبتها بعد الحفظ، مع رسالة نجاح أو خطأ واضحة بلغتك.
2. **إخفاء زر «حفظ الهوية» المنفصل** وإبقاء زر «توثيق وتثبيت» فقط (يحفظ أولاً ثم يوثق).
3. **الصفحة العامة تقرأ الهوية الكاملة:** تظهر شخص أو شركة، المقر، الأسواق، التخصص، والروابط؛ ويُضاف لها كود الآلة (`sameAs`، العنوان، مناطق الخدمة) لتقرأها زواحف الذكاء.
4. **تحديث الصفحة العامة فوراً** بعد الحفظ (تقليل مدة التخزين المؤقت).

## التفاصيل التقنية
- `EntityFields` يصبح مكوّناً متحكماً به: القيم تُرفع للصفحة عبر `value/onChange`، و`profile.tsx` يرسل update واحداً لجدول profiles.
- عند قفل البطاقة لا تُرسل حقول الهوية (لتجنب رفض الحارس).
- `u.$username.ts`: select يشمل entity_type, hq_country, target_markets, specialty_scope, entity_links؛ JSON-LD `@type` Person/Organization، `sameAs`، `address.addressCountry`، `areaServed`، `description`؛ Cache-Control `max-age=30, s-maxage=60`.
- لا تغييرات في قاعدة البيانات. لا نشر.
