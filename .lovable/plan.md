## خطة الإكمال (5 خطوات قابلة للتنفيذ الآن)

### خطوة 1: إصلاح `google_trends` (خطأ برمجي)
- فحص دالة `scrapeGoogleTrends` في `src/lib/pulse-scraper.server.ts`
- إصلاح خطأ `Symbol(Symbol.iterator)` (الـ AI يرجع object بدلاً من array)

### خطوة 2: استبدال `isx` ببديل عملي
- استخدام واجهة JSON بديلة (مثل `isx-iq.net/index.php?ticker=...` أو RSS)
- أو إيقافه مؤقتاً (active=false) لتجنب فشل دوري

### خطوة 3: إنشاء seed بيانات حقيقية على مستوى المحافظات
- إضافة `pulse_seed_data.sql` يدوياً بمؤشرات معروفة لكل محافظة:
  - سكان (من COSIT 2024)
  - مشتركو الإنترنت (CMC)
  - معدل البطالة (MoP)
- يُشغَّل مرة واحدة، يربط `governorate_id` لكل صف
- هذا يحلّ مشاكل compare + gov pages فوراً

### خطوة 4: إصلاح prompts الـAI للمصادر الفارغة (cbi, cmc, hdx, mop)
- مراجعة كل prompt في pulse-scraper.server.ts
- إضافة few-shot examples + تخفيف شروط الإدراج
- اختبار يدوي عبر admin panel "تشغيل الكشط الآن"

### خطوة 5: تحسين عدّاد Uₜ
- بدل صيغة افتراضية، استخدم آخر قراءة "internet_subscribers" من بيانات المحافظة
- إن لم تتوفر، ابقَ على الصيغة الحالية مع تسمية واضحة "تقدير"

## ما يحتاج قراراً منك قبل البدء

1. **`isx`**: هل تريد إصلاحه ببديل أم إيقافه مؤقتاً؟
2. **seed البيانات اليدوية**: هل توافق على إدخال أرقام محافظات معروفة يدوياً لتجاوز فشل الكاشط، أم تفضل انتظار إصلاح الكاشط؟
3. **`trending_apps`**: لا يوجد API مجاني موثوق للتطبيقات في العراق. الخيارات:
   - (أ) إخفاء القسم كلياً
   - (ب) seed يدوي شهري (واتساب، تيك توك، تليجرام...)
   - (ج) محاولة سحب من Google Play "Top free in Iraq" عبر Firecrawl

أخبرني بقراراتك وسأنفذها مباشرة.
