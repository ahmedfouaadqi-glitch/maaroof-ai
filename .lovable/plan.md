## إكمال محرر الرابط الشخصي في صفحة الملف الشخصي

### الجزء المتبقي الوحيد
إضافة قسم JSX في `src/routes/profile.tsx` يعرض ويسمح بتعديل `username` ويُظهر الرابط العام `https://geoiraq.com/u/{username}`.

### التفاصيل

**في `src/routes/profile.tsx`** — إضافة بطاقة جديدة "صفحتك العامة على الإنترنت" تحتوي على:

1. **حقل اسم المستخدم** (input) مع تحقق فوري:
   - 3-32 حرفاً
   - أحرف صغيرة، أرقام، `_` و `-` فقط
   - رسالة خطأ بالعربية عند المخالفة

2. **معاينة الرابط الكامل** بشكل مقروء:
   ```
   https://geoiraq.com/u/[username]
   ```

3. **ثلاثة أزرار**:
   - **حفظ** — يحدِّث `profiles.username` عبر Supabase (مع معالجة تعارض UNIQUE)
   - **نسخ الرابط** — يستخدم `navigator.clipboard`
   - **فتح الصفحة** — يفتح الرابط في تبويب جديد

4. **شرح قصير** ثنائي اللغة (عربي/إنجليزي) يوضح:
   - هذه صفحتك العامة التي يقرأها GPT / Gemini / Claude
   - مرتبطة بـ "متتبع الانتشار" — كل زيارة من زاحف ستظهر هناك
   - مذكورة تلقائياً في `sitemap.xml`

### معالجة الأخطاء
- إذا كان `username` موجوداً بالفعل لمستخدم آخر → رسالة "اسم المستخدم مستخدَم بالفعل، جرّب آخر"
- إذا فشل التحديث → toast خطأ
- عند النجاح → toast نجاح + إعادة تحميل بيانات الملف الشخصي

### لا توجد تغييرات أخرى
- الترحيل (migration) موجود مسبقاً
- المسار `/u/$username` موجود
- `sitemap.xml` يتضمن المستخدمين بالفعل
- منطق التحقق (state) موجود — فقط الـ JSX مفقود
