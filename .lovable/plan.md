# خطة الموجة 3B — تنفيذ بالترتيب

## 1) الصفحة الرئيسية (`src/routes/index.tsx` + `i18n.tsx`) — إعادة كتابة فعلية
المشكلة: التغييرات السابقة لم تُطبَّق على Hero والنصوص الطويلة. سأقوم بـ:
- **Hero**: استبدال نص "8 منصات" بـ "9 منصات ذكاء اصطناعي" + ذكر صريح لـ Kimi ضمن شعارات `EnginesOrbit`.
- **اختصار حقيقي**: حذف كل الأقسام التفصيلية أسفل CTA (How it works الطويل، Features المكررة، Pricing teaser، FAQ). يبقى فقط: Hero → EnginesOrbit → 3 بطاقات قيمة قصيرة → CTA → Footer.
- نقل الشرح المفصّل إلى `/guide` (موجودة).
- مراجعة كل مفتاح `hero_*`, `feature_*`, `compare_*`, `cta_*` في `i18n.tsx` لثلاث لغات للتأكد من ذكر **9** وعدم وجود نص عربي متسرّب في `en/ku`.

## 2) `ReportBuilder.tsx` — تحسين بصري فعلي
المشكلة: الألوان باهتة، التباين ضعيف، البطاقات غير واضحة. سأقوم بـ:
- استبدال palette من `hsl(var(--primary))` إلى ألوان OKLCH صريحة عالية التباين (6 ألوان متباينة).
- خلفية المخطط: `bg-card` مع `border-2` وحدود واضحة.
- البطاقات السفلية: تكبير الأرقام، أيقونات ملوّنة، gradient حدّي خفيف.
- Tooltip: خلفية صلبة (ليس شفافة) لقراءة أفضل.
- Grid lines أوضح، محاور بخط أسمك.
- إضافة عنوان وصفي فوق كل مخطط.

## 3) لوحة إدارة المحتوى الجديدة `/admin/content` — بطاقات بسيطة باللغة الفعّالة
بدل جدول 3 أعمدة معقّد، **بطاقات**:
- كل مفتاح i18n = بطاقة واحدة.
- البطاقة تعرض: اسم المفتاح (صغير، مخفي افتراضياً) + **النص بـاللغة المختارة حالياً فقط** (textarea كبير قابل للتعديل مباشرة).
- زر تبديل لغة في أعلى الصفحة (ar/en/ku) — تغيير اللغة يغيّر ما يُعرض في كل البطاقات.
- شريط بحث + فلتر مجموعات (homepage / dashboard / tools / agent…).
- زر "حفظ" أسفل كل بطاقة عند التعديل، مع زر "ترجمة تلقائية للغات الأخرى" (Lovable AI — `google/gemini-2.5-flash`).
- **Schema جديد**: `content_overrides (id, key text, lang text, value text, updated_at, updated_by uuid)` + index على `(key, lang)` + RLS (admin write, public read) + GRANTs كاملة.
- `useI18n` يُدمج `content_overrides` فوق القاموس الأساسي (cache عبر React Query).

- التأكد أن `EnginesOrbit` يعرض 9 شعارات (Kimi مضاف).
